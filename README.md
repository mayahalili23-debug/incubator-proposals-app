# הצעות שיבוץ, אפליקציית דשבורד למאנדיי

קובץ סטטי אחד, `index.html`, שרץ כ-Dashboard Widget בתוך monday.com.

## מה זה מכיל

קוד תצוגה בלבד. הוא קורא הצעות שיבוץ מבורד monday ומאפשר לסמן הצעה,
והכל **בהרשאות של המשתמש שצופה בו**, דרך seamless authentication של monday.

## מה זה לא מכיל

**אין כאן שום סוד.** לא טוקן, לא מפתח, ולא נתוני לקוח. הנתונים מגיעים
מ-monday בזמן ריצה, ורק למי שיש לו גישה לחשבון. לצופה מבחוץ הקובץ הוא שלד ריק.

## אירוח

הקובץ מוגש דרך GitHub Pages, ומאנדיי טוענת אותו כ-`External hosting`.

מקור האמת לקוד הוא `app/proposals_view.html` בפרויקט `monday-matcher`.
הריפו הזה הוא יעד פריסה, ואין לערוך אותו ידנית.
